## Implementation Details

### INT4 KV Cache Algorithm
```cpp
// Quantization: float → int4
float v_float = input[i];
float v_scaled = v_float / 8.0f;  // quantScale
int8_t q = clamp(round(v_scaled), -8, 7);  // 4-bit range

// Packing: 2 values per byte
uint8_t packed = (high << 4) | (low & 0x0F);

// Dequantization: int4 → float
int8_t q = extract(packed);
float v_float = float(q) * 8.0f;  // quantScale
```

**Compression:** 50% memory usage (2 floats → 1 byte)

### Dynamic Batching Algorithm
```cpp
// EMA thermal baseline tracking
baseline = (1 - α) * baseline + α * latency;  // α = 0.1

// Throttling detection
if (latency > 1.3 * baseline) {
  // Aggressive scale down
  maxBatch = max(1, maxBatch * 0.7);
}

// Recovery
if (fastBatchCount >= 5) {
  // Conservative scale up
  maxBatch = min(configMax, maxBatch + 1);
}
```
