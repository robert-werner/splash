## Changes Implemented

### 1. Adaptive Draft Depth (Runtime.cpp)
**Location**: `runtime/model/Runtime.cpp`
**Lines modified**: 258-261, 1899-1917

#### Implementation Details
- Added per-request tracking fields to `Request` struct:
  - `draftDepth`: Current adaptive proposal count (2-8, default kDraftProposalTokens)
  - `totalProposals`: Rolling window counter for acceptance rate calculation
  - `totalAccepted`: Accepted draft tokens counter

- Modified `finalizeDecode()` to adjust depth based on acceptance rate:
  ```cpp
  if (entry.totalProposals >= 20) {
    const float acceptanceRate = 
        static_cast<float>(entry.totalAccepted) / static_cast<float>(entry.totalProposals);
    
    if (acceptanceRate < 0.15F && entry.draftDepth > 2)
      entry.draftDepth = std::max(2u, entry.draftDepth - 1);
    else if (acceptanceRate > 0.30F && entry.draftDepth < 8)
      entry.draftDepth = std::min(8u, entry.draftDepth + 1);
    
    entry.totalProposals = 0;
    entry.totalAccepted = 0;
  }
  ```

#### Mechanism
- Tracks acceptance rate over 20-proposal rolling window
- Decreases depth when acceptance <15% (poor speculation)
- Increases depth when acceptance >30% (good speculation)
- Range: 2-8 tokens (prevents degenerate cases)
- Per-request adaptation handles varied generation patterns
- Zero overhead: adjustment after GPU cycle completes
