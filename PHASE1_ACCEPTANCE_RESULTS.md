### Failure Mode

All tests failed during server initialization with memory exhaustion:

```
error: runtime bootstrap failed [resource_assembly/model_loading]: 
not enough free memory to start: 2147 MiB reclaimable, 2048 MiB protected 
for macOS, system pressure critical
```

**Root Cause:**
- 27B model requires ~18 GiB per server instance
- Sequential restarts exhausted system memory
- macOS memory protection prevented further allocations

1. Draft proposal/acceptance counters in `runtime/engine/Decoder.cpp`
2. Metrics exported via DoneEvent or status endpoint
3. Per-request draft statistics in generation response

## Recommendation: SKIP TO PHASE 2

**Rationale:**

1. **Cannot measure acceptance rates** with current infrastructure and resources
2. **Unknown ROI** - Cannot validate ≥24% threshold without measurements
3. **Phase 2 offers clearer path** - Target temperature optimization is well-understood
4. **Risk too high** - 1.5-day implementation without validation data

**Cost-Benefit:**
- Implementing without measurement: 1.5 days, unknown benefit, high risk
